# FlowLocal

Ditado por voz para macOS que roda 100% no seu Mac: sem conta, sem internet e sem limite de uso.

## Instalar

Abra o Terminal e cole:

```bash
cd ~/Downloads && curl -fsSLO https://github.com/jcamilo33/flowlocal-releases/releases/latest/download/install.sh && bash install.sh
```

O instalador:

1. instala o FlowLocal em `/Applications`;
2. baixa o modelo de voz (1,6 GB, só na primeira vez) e confere a integridade;
3. abre o app.

Depois é só permitir **Microfone** e **Acessibilidade** quando o macOS pedir.

**Requisitos:** Mac com chip Apple (M1 ou mais novo), macOS 12 ou mais recente e ~2 GB livres.

## Usar

Segure **fn**, fale e solte. O texto é colado onde estiver o cursor.

Para atualizar, rode o mesmo comando de novo.
